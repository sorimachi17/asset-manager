# Market dataset sources and licensing

- CNN Fear & Greed history: https://github.com/whit3rabbit/fear-greed-data
  The upstream repository makes its code and dataset available under the MIT License.
  It compiles historical values from several sources; the earliest values are estimates.
- Cboe VIX: https://www.cboe.com/tradable-products/vix/vix-historical-data/
  VIX is a Cboe index and its data may have redistribution requirements.
  Check Cboe licensing before making this public app available to others.
- Nikkei 225 VI: https://indexes.nikkei.co.jp/nkave/index/profile?idx=nk225vi
  The app deliberately does not republish Nikkei's CSV; users download it
  themselves and import it into their browser's local storage.
